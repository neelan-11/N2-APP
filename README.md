# N²

N² è una PWA gamificata per tracciare task e abitudini con XP, livelli, badge, statistiche e personaggio personalizzabile.

## Installazione su iPhone

1. Apri il sito pubblicato con Safari.
2. Tocca **Condividi**.
3. Tocca **Aggiungi alla schermata Home**.
4. Conferma **Aggiungi**.

L'app usa un service worker per il funzionamento offline e salva i dati localmente sul dispositivo.
